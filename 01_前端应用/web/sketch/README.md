# 参数化草图 · Parametric 2D Sketch CAD

把照片、扫描图纸和手绘草图变成**可参数化编辑的工程草图**：几何由尺寸与几何约束定义，改一个尺寸全图联动，结果按工程规范导出 DXF（R12），可在 AutoCAD 中直接打开继续编辑。

本模块是「参数化二维工程草图 CAD」定位的落地实现，独立于原有「手动绘图 / AI 识图 / 3D 预览」三入口，从门户第 1 张卡片进入。

---

## 快速开始

```bash
cd image2cad/..            # 工程源目录（含 image2cad 包）
py -m image2cad.server --port 8799
```

浏览器打开：

```
http://127.0.0.1:8799/static/sketch/index.html
```

或从门户首页（`http://127.0.0.1:8799/`）点「参数化草图」卡片。

> 页面走 `/static/` 静态路由，**不需要改后端**：`web/sketch/` 下的文件原样由现有 `http.server` 提供。
> 打包 exe 时 `CADEngine.spec` 的 `datas` 已包含整个 `image2cad/web`，新增目录会一并打进包内。

## 界面与操作

```
┌ 顶栏：求解状态徽标 · 示例 · 适应视图 · 撤销/重做 · 保存/载入 · 导入/导出 DXF · 打印 PDF · 帮助
├ 左：绘图工具（选择/直线/矩形/圆/圆弧/点）+ 几何约束 13 种 + 尺寸约束 6 种
├ 中：SVG 画布（网格 / 图元 / 尺寸标注 / 约束标记）+ 底部状态栏
└ 右：求解诊断（自由度/冗余/冲突）· 约束 / 图元 双页签 · 特性
```

- **绘图**：`L` 直线、`R` 矩形、`C` 圆、`A` 圆弧、`P` 点；`Esc` 回选择。
- **自动约束**：画线角度在 2° 内自动加水平/竖直约束；矩形自动加四边水平/竖直；捕捉到端点直接复用该点。
- **选择**：单击选中、`Shift` 多选、空白拖框选；拖动点/图元时实时求解（拖动点视为临时固定）。
- **图元树**：右侧「图元」页签列出全部对象（类型 + 长度/半径/坐标），单击选中、双击缩放到该对象。
- **加约束**：先选图元再点约束按钮；矩形绘制时自动加水平/竖直约束。
- **尺寸驱动**：在右侧约束列表直接改数值，回车后几何联动（如 120 → 200，全图跟着变）。
- **诊断**：状态徽标显示「完全约束 / 欠约束 n DoF / 约束冲突」；冲突约束在画布标红，并列出具体是哪几条。
- **撤销/重做**：`Ctrl+Z` / `Ctrl+Y`，命令级回滚（含求解后的几何）。
- **AI 建模（自然语言）**：底部「AI 建模」输入框，说人话生成图元：`画一个长120宽80的矩形`、`在中心打一个直径30的孔`、`把长度改成150`、`清空`；一句话里「矩形 + 孔」也行。离线规则解析，不需要大模型 Key。
- **草稿**：保存/载入浏览器本地草稿（`sketch.draft.v1`）。
- **导出**：DXF R12，几何走 `0` / `CONSTRUCTION` 层，标注走 `DIM` 层（LINE + TEXT）。
- **打印 / PDF**：`Ctrl+P` 或「打印 / PDF」按钮，A4 横向、隐藏网格与界面，浏览器「另存为 PDF」得到矢量图纸。

## 支持的约束（19 种）

| 类别 | 约束 | 说明 |
| --- | --- | --- |
| 几何 | 重合 coincident | 两点（含圆弧端点）重合 |
| 几何 | 水平 / 竖直 horizontal / vertical | 直线方向 |
| 几何 | 平行 / 垂直 parallel / perpendicular | 两直线夹角 |
| 几何 | 相切 tangent | 直线与圆/弧 |
| 几何 | 等长 / 等半径 equalLength / equalRadius | 两线 / 两圆 |
| 几何 | 对称 symmetric | 两点关于直线对称（2 方程） |
| 几何 | 中点 midpoint | 点在直线中点（2 方程） |
| 几何 | 点在线上 / 点在圆上 pointOnLine / pointOnCircle | 点约束到曲线 |
| 几何 | 固定 fix | 锁定点坐标 |
| 尺寸 | 距离 distance | 两点距离（mm） |
| 尺寸 | 水平距 / 竖直距 distanceX / distanceY | 坐标差（mm） |
| 尺寸 | 半径 / 直径 radius / diameter | 圆或弧（mm） |
| 尺寸 | 角度 angle | 两直线有向夹角（°） |

约束方程写在 `js/constraints.js`，全部归一化（角度用三角函数、距离用真实长度差），避免长线/大半径主导残差。

## 求解器

- **算法**：Levenberg–Marquardt，数值雅可比（中心差分）；阻尼 `λ` 失败 ×10、成功 ÷3，失败自动回滚到上一有效状态。
- **诊断**：`自由度 = 变量数 − rank(J)`，`冗余 = 方程数 − rank(J)`；收敛失败时按残差定位冲突约束。
- **拖动**：被拖动的点临时移出变量集（固定），只解其余自由度，保证手感稳定。
- **规模**：2D 草图变量 < 100、约束 < 100 时，单次求解在毫秒级。

> 与 FreeCAD `planegcs` 的关系见 [`docs/参考与借鉴.md`](docs/参考与借鉴.md)：约束种类与「自由度/冗余/冲突」诊断口径对齐 FreeCAD Sketcher，求解器按 2D 草图规模自研。

## 性能（2026-11-07 实测，浏览器内）

| 场景 | 改前 | 改后 |
| --- | --- | --- |
| 拖动帧（30 个矩形 / 120 点 / 180 约束，解 + 渲染） | ~100 ms/帧 | **p50 4.9 ms / p90 7.1 ms** |
| 求解 10 组矩形 | 25.7 ms | 13.6 ms |
| 求解 30 组矩形 | 44.9 ms | 31 ms |
| 求解 60 组矩形 | 156.9 ms | 115 ms |
| 渲染 30 组矩形 | 6.4 ms/帧 | 6.2 ms/帧 |
| 页面加载（DOMContentLoaded） | — | ~230 ms |

做法：

- **雅可比**：中心差分 → 前向差分（求值次数减半）；变量按「变量→实体字段」直接扰动，不再每次全量 `applyVars`。
- **变量下标缓存**：结构不变时复用（增删图元时失效）。
- **拖动只解受影响子图**：按「实体 ↔ 约束」连通分量求子图，其余图元保持不动。
- **拖动迭代上限压到 6**（热启动足够），落点再全量求解保证精度。
- **指针事件 rAF 合帧**：高于 60Hz 的 pointermove 不再每事件解一次。
- **面板刷新 140ms 节流**：拖动时不重建右侧列表。

## 已知边界（本版）

- 不做三维、布尔运算、装配；定位就是二维工程草图。
- 图元类型：点 / 直线 / 圆 / 圆弧；暂不含椭圆、NURBS、样条。
- 图层管理（新建/锁定/线宽）尚未实现，导出图层固定为 `0` / `CONSTRUCTION` / `DIM`。
- DXF 导入当前映射为「几何图元」，不还原约束关系。
- 标注导出为 LINE + TEXT（R12 DIMENSION 依赖块定义，跨软件兼容性差，故不用）。
- 打印 / PDF 走浏览器打印（矢量输出），A4 横向固定；标题栏与图层样式将在后续版本补齐。

- 右上「图元」页签：对象树，单击选中、双击缩放到对象。
- 自动约束：画线 2° 内自动加水平/竖直；矩形四边自动约束（上一轮已有）。
- 冲突可读化：诊断面板直接列出冲突约束的中文描述与数值。
- 打印 / PDF：A4 横向矢量图纸输出，隐藏网格与界面。
- 草稿保存后可「载入草稿」恢复。
- 面板刷新节流：拖动/缩放不再每帧重建列表（手感更稳）。
