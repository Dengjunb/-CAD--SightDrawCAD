特性

参数化草图 · 操作速查

  • 绘图：L 直线 / R 矩形 / C 圆 / A 圆弧 / P 点；Esc 回到选择；画线接近水平/竖直会自动加约束
  • 选择：单击选中，Shift 多选；空白处拖框选；拖动点或图元实时求解
  • 图元：右侧「图元」页签列出全部对象，单击选中、双击缩放到该对象
  • 加约束：先选图元（点/线/圆），再点左侧约束按钮
  • 尺寸：右侧约束列表里直接改数值，几何立即联动
  • 撤销/重做：Ctrl+Z / Ctrl+Y；Delete 删除选中
  • 视图：滚轮缩放（以光标为中心），中键 / Alt+左键平移
  • 导出：DXF R12（可在 AutoCAD 直接打开）；「打印 / PDF」输出矢量图纸（Ctrl+P）

求解器：Levenberg–Marquardt + 数值雅可比；诊断给出自由度、冗余约束与冲突约束。
