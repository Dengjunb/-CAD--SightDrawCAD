# 运行程序（按软件架构分卷，每卷 ≤ 95 MB）

本目录是**可运行程序**（识绘CAD），按架构分为 4 组，每组再分卷，每卷 ≤ 95 MB。
双击 **`启动-组装并运行.bat`**：脚本会把分卷还原成完整程序（`运行目录/`）并启动。

## 目录

| 目录 | 内容 | 分卷 |
| --- | --- | --- |
| `01_桌面壳/` | Electron 运行时（识绘CAD.exe 切片 + dll/pak/locales） | 卷1 82.6 MB / 卷2 95.0 MB / 卷3 73.6 MB |
| `02_前端资源/` | resources/app.asar + ai_config.json | 文件 0.0 MB |
| `03_引擎程序/` | resources/backend/CADEngine.exe | 文件 10.5 MB |
| `04_引擎依赖/` | resources/backend/_internal（Python 依赖） | 卷1 18.1 MB / 卷2 82.3 MB / 卷3 86.0 MB |

`拆分清单.json` 记录每卷文件数与体积；`识绘CAD.exe` 被切成 `.part01/.part02`，组装时用 `copy /b` 合并。

## 使用

1. 双击 `启动-组装并运行.bat`
2. 等待 10–30 秒（复制约 450 MB 到 `运行目录/`）
3. 程序自动启动；`运行目录/` 可反复使用

> 只组装不启动：`powershell -ExecutionPolicy Bypass -File .\assemble.ps1 -NoLaunch`
