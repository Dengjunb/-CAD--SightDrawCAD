# AI 全自动生成 3D

一张图 → 自动识别 → 轮廓 → 拉伸实体 → 预览 → STL / OBJ。

## 用法

门户首页「AI 全自动 3D」，或直接打开：

```
http://127.0.0.1:8799/static/3d/index.html
```

- **选择图片 / 示例图**：走现有识别接口 `POST /api/run`（`{demo}` 或 `{name, data_b64}`）。
- **从草图导入**：在参数化草图页点「发送到 3D」，或在本页点「从草图导入」——读取浏览器草稿 `sketch.draft.v1`，把矩形/圆/闭合轮廓直接拉伸，不再走识别。
- 页面轮询 `/api/status/<runId>`，识别完成后自动取 `result.scene`。
- **拉伸高度**：2–120 mm 滑块，改完立即重建网格。
- **导出 STL / OBJ**：单实体、水密性对打印够用；OBJ 可直接进 Blender / CAD。
- 拖动旋转、滚轮缩放。

## 算法

1. **轮廓收集**（`js/mesh.js`）：圆 → 48 边形、矩形 → 4 点、闭合多段线原样；像素坐标换算成 mm（`X = px·scale`，`Z = -py·scale`，Y 为高度）。
2. **主轮廓识别**：面积最大者为外形；若其包围盒铺满 90% 以上整图（典型图框），改用次大轮廓。
3. **孔判定**：其余轮廓完全落在主轮廓内 → 孔。
4. **三角化**：孔用「最右点射线桥接」并进外环，再做耳切（ear clipping）；失败自动降级为无孔三角化。
5. **拉伸**：底面 + 顶面 + 侧壁（外轮廓朝外、孔壁朝内），输出 `{verts, faces}`。
6. **渲染**（`js/viewer.js`）：Canvas 2D 画家算法 + 平面着色，零依赖；导出 `meshToSTL` / `meshToOBJ`。

## 边界（本版）

- 只做**等高度拉伸**：不支持多高度、抽壳、倒角、螺纹。
- 只取**一个主轮廓**：多零件图会只生成最大的那一个。
- 孔为「完全包含」判定；相交/贴边的轮廓不会当孔。
- 识别质量决定 3D 质量：轮廓断线会导致孔缺失或外形缺口；可先在识别页调参数再回来。
